# AI Usage Report

## Tools Used and Use Cases

I used ChatGPT as an AI-assisted development tool during this assignment.

I used ChatGPT for:

- Planning the structure of the portfolio website.
- Generating suggestions for HTML sections, CSS styling, and JavaScript interactions.
- Understanding responsive design using CSS Grid and Flexbox.
- Adding a light and dark theme toggle.
- Reviewing the README and technical documentation.
- Checking the organization of the project files.

## Benefits and Challenges

AI helped me begin the project with a clear file structure and gave me ideas for creating a responsive layout. It also helped explain JavaScript concepts such as event listeners, local storage, and form submission.

One challenge was that some generated code needed to be reviewed and adjusted. I had to check that file paths were correct, that the design worked on small screens, and that the JavaScript matched the HTML element IDs.

## Learning Outcomes

Through this assignment, I learned how to:

- Create a semantic HTML page with multiple sections.
- Use CSS variables to support light and dark themes.
- Create responsive layouts using CSS Grid and media queries.
- Use JavaScript event listeners.
- Store a theme preference using localStorage.
- Create a form interaction without a backend.
- Organize website files into separate HTML, CSS, JavaScript, and documentation files.

## Responsible Use and Modifications

I did not submit AI-generated content without reviewing it. I read through the code, changed the design, replaced placeholder text, and tested the website in a browser.

I also checked that the JavaScript functions matched the HTML IDs and that the website remained understandable. The final project was modified to reflect my own information and learning.
