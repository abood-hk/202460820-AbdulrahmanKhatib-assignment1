# Technical Documentation

## Project Overview

This project is a responsive personal portfolio website created using HTML, CSS, and JavaScript.

The website contains:

- An About Me section
- A Projects section
- A Contact section
- A light and dark theme toggle
- A time-based greeting
- A contact form confirmation message

## Technologies Used

- HTML5
- CSS3
- JavaScript
- CSS Grid
- CSS Flexbox
- localStorage
