# Abdulrahman Khatib - Portfolio Website

## Project Description

This project is a simple, responsive personal portfolio website created for Assignment 1: Foundation & AI Integration.

The website introduces me, displays sample projects, and provides a contact form. It was built using HTML, CSS, and JavaScript.

## Features

- Responsive design for desktop, tablet, and mobile screens
- About Me section
- Projects section with two sample projects
- Contact form
- Light and dark theme toggle
- Greeting message based on the time of day
- Smooth scrolling navigation
- Clean and organized file structure

## Technologies Used

- HTML5
- CSS3
- JavaScript
- CSS Grid
- CSS Flexbox
- localStorage
